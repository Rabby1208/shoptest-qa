# ShopTest QA — Manual Test Plan

## 1. Project Overview
ShopTest QA is a mini e-commerce web application developed to practice manual and automation testing.

## 2. Testing Objectives
- Verify that all major website features work correctly.
- Identify functional and validation errors.
- Check shopping cart and checkout functionality.
- Ensure the application provides a smooth user experience.

## 3. Scope of Testing
The following features will be tested:
- Product listing
- Add to Cart
- Cart item quantity update
- Remove product from cart
- Cart total calculation
- Checkout form validation
- Order placement and confirmation
- Basic responsive layout

## 4. Testing Approach
Testing will initially be performed manually using a web browser. Actual results will be compared with expected results, and defects will be documented.

## 5. Test Environment
- Operating System: Windows
- Browser: Microsoft Edge or Google Chrome
- Application: ShopTest QA
- Testing Type: Manual Functional Testing and UI Testing

## 6. Entry Criteria
The application files are available, and the website opens in a browser.

## 7. Exit Criteria
All planned test cases have been executed, results have been recorded, and identified defects have been documented.

## 8. Deliverables
- Manual Test Plan
- Test Cases
- Test Execution Results
- Bug Reports
- Test Summary Report
